# collabKanban

## Overview
Package-path folder for the `com.collabKanban` namespace. It has no source
files of its own. All code is in the `Kanban` package.

## Subdirectories & Boundaries
- Kanban: [`./Kanban/README.md`](./Kanban/README.md) - the Spring Boot
  application root and all feature packages (users, workspaces, teams, boards,
  cards, security, STOMP).
